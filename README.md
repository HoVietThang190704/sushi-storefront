# Sushi Storefront

Customer storefront web application for Sushi Platform (Next.js 16 + Tailwind CSS v4 + shadcn/ui).

## Tech Stack
- **Framework:** Next.js 16 (App Router, Turbopack)
- **Styling:** Tailwind CSS v4, Lucide Icons
- **UI Components:** shadcn/ui
- **Form & Validation:** React Hook Form, Zod
- **State Management:** Zustand

## Getting Started

```bash
pnpm install
pnpm dev
```

App runs on [http://localhost:3006](http://localhost:3006).

API Gateway proxy routes `/api/*` to `http://localhost:3000/api/*`.
